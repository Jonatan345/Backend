# Sistem Integrasi Bima Resto - Backend API 🍽️

Proyek ini adalah bagian Backend dari Sistem Integrasi Bima Resto (Capstone Project - Pradita University). Backend ini dibangun menggunakan Node.js dan Express.js, serta terhubung dengan PostgreSQL berbasis Cloud (Neon) untuk manajemen data restoran yang cepat dan andal.

Selain API utama, proyek ini juga mencakup server terpisah untuk Kitchen Display System (KDS) yang memantau pesanan di dapur.

## 🚀 Teknologi yang Digunakan
* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** PostgreSQL (via [Neon.tech](https://neon.tech))
* **Library:** `pg` (node-postgres), `cors`, `dotenv`

## ⚙️ Persyaratan Sistem
